# docs/

Documentación del proyecto. El orden de lectura para agentes está en `CLAUDE.md`, en la raíz.

| Archivo | Qué es | Naturaleza |
|---|---|---|
| `01-brief.md` | Qué se construye, para quién, con qué estructura | Requisito |
| `02-design-system.md` | Tokens, tipografía, componentes, movimiento | **Normativo** |
| `03-content.md` | Copy final, literal | **Normativo** |
| `04-engineering.md` | Stack, estructura, convenciones, accesibilidad, rendimiento | **Normativo** |
| `05-roadmap.md` | Orden de construcción por fases | Proceso |
| `estructura/` | Documentación de negocio de la empresa | **Solo consulta** |

## Sobre `estructura/`

Contiene los diez documentos de estrategia, servicios, precios, proceso comercial, delivery, legal, marca y plantillas de DevBro Solutions.

**No son requisitos de build.** Sirven para entender por qué el copy dice lo que dice o por qué una sección existe. Ningún agente debe implementar algo que salga únicamente de esa carpeta.

Si un documento de `estructura/` contradice a `01`–`05`, mandan `01`–`05`. Y avisá de la contradicción.
