## Lo que quedó definido en la v0.2

| Tema | Decisión |
|---|---|
| Posicionamiento | Vendemos certeza y salida limpia. El precio bajo y la velocidad son consecuencia, no promesa |
| Diferenciador principal | **+10 años de experiencia** construyendo a código puro, sistemas del mismo tipo ya construidos antes. La IA multiplica; no es el motor |
| Arquitectura como argumento | Capa de datos mediada por ORM → portable. El cliente puede migrar de nube o autohospedar. Antídoto directo contra el no-code |
| SONDA | 5 días hábiles · USD 1.200 · requiere ~6 h del cliente · se descuenta del proyecto |
| LANZAMIENTO | **3 a 6 semanas** + 2 de diagnóstico · **desde USD 5.000**, techo 9.500 |
| EXPEDICIÓN | **8 a 14 semanas** · desde USD 14.000 |
| Diagnóstico | Bolsa de 12 h (24 h en EXPEDICIÓN), anunciada por adelantado y registrada |
| Enlace de talento | Fee fijo al cliente, tres niveles. Nunca al candidato, nunca % del salario |
| Medios de cobro | Payoneer (preferido), transferencia, efectivo, stablecoins. Stripe pendiente de entidad |
| Estructura legal | Interino: persona natural con nombre comercial DevBro Solutions. **Sin "S.A."** hasta que exista |
| Marca | Neobrutalismo · verde **metálico sobrio**, nada fluorescente · elemento firma: placa troquelada |
| Landing | Solo la fábrica. Los productos propios van a otro dominio |
| Objetivo de fondo | La fábrica financia el lanzamiento de **startups propias** |
